# Reproducibility evidence

`fml run-all` was run twice in a row (2026-10-17, LLM and stance answers from the committed caches, no API
calls, `evaluate-final` not run). After each run the SHA-256 of `results/metrics.json` and every file in
`results/tables/` was recorded. The two lists below are identical. They also match the committed files
(`git status results` showed only `run_info.json` changed, which holds the timing: 98.7 s and 98.4 s,
limit 480 s). `results/test_access_log.jsonl` was not touched.

Check it yourself: run `fml run-all`, then `sha256sum results/metrics.json results/tables/*` and compare.
